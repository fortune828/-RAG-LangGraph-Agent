# 语料来源与校勘状态

本地学习演示语料，版本见 manifest.json；共963条记录。数据不由LLM编造。

- 主要来源：[Open I' Ching](https://github.com/john-walks-slow/open-iching)，固定提交 `4c5f00f8cb62c6e0d2471243d28150b473ef592f`。
- 保留 `upstream/iching.json`、`tuan.json`、`xiang.json`、`names.json` 和 Readme；SHA-256记录于manifest。
- 上游Readme明确注明“仅供学习交流使用，不得用于商业用途”。本仓库这份导入数据用于本地学习/简历演示，商业发布前须替换为授权清晰的版本或另获授权。未将上游工具代码的ISC声明套用到数据上。
- 结构覆盖：64卦辞、384基本爻辞、用九/用六、63彖传、64大象及对应小象。缺少第32卦恒卦彖传，按缺失处理，不用模型补齐。
- 未导入现代注解、系辞、朱熹注等。关键词检索仅在实际收录的古文中搜索，不宣称语义RAG或现代注解检索。
- 上游仍处于建设中，文本未完成逐条人工校勘；可追溯不等于权威校订。不要把检索覆盖率当作古文准确率。

## 明确的校勘记录

已对照[维基文库《周易·乾》固定修订2404991](https://zh.wikisource.org/w/index.php?title=周易/乾&oldid=2404991)核对九二爻辞及小象：上游“见龙再田”改为“见龙在田”。对应两条记录直接指向该来源，原始快照不变；变更由build-corpus.ts重建。页面注明CC BY-SA 4.0，原典属古文；保留来源与变更归属，新增现代解释未冒充原典。

V1第15、16卦编码修正另由规则数据和独立编码表验证，与文本校勘分开记录。

## 重建

`npm run corpus:build` 从仓库内固定快照离线重建，无需网络。改动上游版本或校勘规则时必须更新语料版本，再重新评测。
