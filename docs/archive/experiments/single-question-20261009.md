# 单核心问题会话与上下文修订 · 2026-10-09

当前 `python-graph-v7` / `evidence-agent-python-v9`，模型为开启思考模式的 `deepseek-flash`。不新增服务、分类模型、长期记忆、段落类型或接口状态。

## 产品规则与实现

一个聊天围绕一个核心问题发问、起卦并分析。同题补充、事实纠正、比较选项、解释和出处核对继续使用原卦；新的独立问题必须点击“新建起卦”，新开聊天、重新起卦。新会话不带入旧会话消息，不自动删除旧业务记录，也不在当前会话自动重掷。页面首页和追问区已明确说明。

- prepare 识别明确换题或要求重起卦，直接返回固定操作提示；没有模型或工具调用。
- 现有 route 可返回 `newTopic=true` 判断隐含换题，由程序直接到 finish，不再检索或回答新题。含糊表达先结合核心问题理解，必要时由生成澄清。LLM 语义判断不保证覆盖所有表达。
- 医疗／投资／自伤等风险支持优先于换题拦截，尤其不能让新建聊天延误危急求助；不对新的风险话题继续解卦。
- 生成输入加入核心问题及有角色区分的近期对话。最多六轮、序列化总量不超过 6000 字符；单轮助手正文保留至多 1800 字符并标注节选。没有生成式摘要；用户最新纠正和助手旧意见不混成同一种事实。只传递实际使用的文本，解决“按旧助手全文计费但生成只用用户发言”的预算错配。
- 长答案可能仍被截取，有限窗口外的细节仍可能遗失；没有宣称拥有完整记忆。旧助手内容不能直接充当新引用证据，引用仍须在本轮原文集合中校验。
- 通用提示词保留稳定的来源、段落及输出规则；当前回答任务在 generation_messages 提供。书名／作者触发检索提示时不再要求只能回答出处，模型可根据用户实际目的解释和类比；服务端证据目标与权限仍保留。意图初筛仍是有限规则，并未升级为完整语义分类。
- 风险提示收紧到必要风险说明、最少可行步骤和关键澄清，不自行制定用药、仓位、还债次序、冷静期限，不把可能亏损写成必然，不推断心理。

## 保留的首次失败

提示词压缩到 v7 时，首轮 life-initial 把岗位、收入等现实建议混入 interpretation，虽有真实引用仍机械通过。因此补回“interpretation 不写现实建议或面向用户的类比”，该次修订为 v8。这不禁止生活追问引用，而是让解释和现实联想分别表达。

[v7 原始运行](../../../evaluation/results/development-real-20261009-023953-5db052/report.json) 保留；完成生活链五个场景后，在 source-line 请求期间主动中断，后续未执行。原始记录中 source-line 仍标为 not_run，但已计一次请求，不能据此理解为没有费用。中断请求没有取得 usage，报告 reportedTokens 只是已收到用量，accountedTokens 含保守预留；不汇总成“全部真实用量已知”。

## 验收边界

语义复核为 AI 辅助阅读，没有真人盲评或专家审校。新聊天规则解决跨主题混用，不意味着同题重复、传统释义支持度及回答简洁性已经完全解决。T01、T05、T13 不因机械通过就自动关闭；此前历史记录保持，不改写旧结果。


## 后续真实失败与修正

v8 完整开发运行中，医疗与危机场景的非法 kind／引用结构在一次修复后仍失败。根因之一是 repair 不分任务，给风险回答也追加了“补传统解释”的指令，重新诱导索要卦象。现在沿用同一 repair 节点，对风险仅修复 reflection JSON、移除解卦与原文缺失说明；不放宽 schema。增加对应的可控故障回归。

同题生活回答仍频繁以“原文不涉及职业”作限制。v9 补充：现实建议可根据用户条件及一般常识，不需要古文直接讨论职业或收入。未恢复把古文当现实预测的权限。

隐含换题另有真实模型验证：工作为核心问题时改问孩子转学，现有 route 返回 newTopic，程序只提示新建聊天，未检索或作新题解读；1 次请求、4,838 tokens，原卦保持。[原始记录](../../../evaluation/results/single-question-implicit-20261009.json)。该探针为 v8；v9 未改换题路由逻辑。

- 最终 Python 89 项通过，包括风险格式失败后的专用修复。浏览器运行时为较早 v7 提示词候选，后续仅修改生成／修复要求，UI 和接口未变；最终语义依上述真实运行判断。

最终生活纠正回答自行选择不引用，不再整段重解卦；同题已有条件能够延续。风险两例没有再索要原文或返回非法 kind，未猜具体地区号码。明确换题以及隐含新题均有验证记录。

仍有边界：首次解释偏长、逐段重复限制，部分传统释义未由对应短引文充分支持；生活现金流建议可能出现重复扣除房租的含糊算法；生活追问有时补检索较多。最新历史窗口样例仍列举记录，风险支持也不代表已完成全面安全验收。它们属于下一步语义质量工作，不通过新增复杂框架或放松机械校验掩盖。
