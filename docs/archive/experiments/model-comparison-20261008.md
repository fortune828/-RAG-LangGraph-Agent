## 回答对比与错误原因

- **首次解读退化为纯建议，导致技术失败。** `life-initial` 首次生成和一次修复都触发 `MISSING_ANSWER_CITATION`。最终候选仅一个 reflection 段，讲储蓄、收入结构与过渡方案；没有对应乾卦的传统解释和引用。固定证据实际已取得（卦辞、彖传、大象），不是检索失败或 API 不可用。校验正确保留了首次解读的产品要求，未放松规则让它通过。
- **当前生成契约仍有表达缺口。** 生成输入有卦象和“传统问题须有依据”的提示，却未明确传达“本轮是首次解读，必须包含一段有依据的传统解释”。修复又主要强调段落引用规则，未把 `MISSING_ANSWER_CITATION` 转成具体补充要求。Pro 选择只给现实建议，暴露了此处不一致。后续宜针对该错误补足明确生成要求及修复反馈，而非强迫生活追问引用或更换模型后堆叠规则。本轮未修改这些逻辑，以保留模型切换结果。
- **合租回答更直接。** `life-topic-change` 只给无引用的家务协商建议，不再重复乾卦解释，也未串入积蓄事实；但仍未主动说明沿用原卦的边界。补充积蓄和纠正积蓄场景仍重复传统解释，问题未全面解决。
- **历史缺失更简洁。** `history-window` 不再枚举第 1～6 项历史，不猜 17 个月；仍在 limitations 提及历史有限，正文与摘要重复。
- **缺失作者回答更短。** `source-missing` 零工具、不用他家替代，明确无法提供所问材料；但仍将“未收录”和“未取得”混用，没有完全改善精确缺失范围的表达。
- **风险回答没有改善到可关闭。** 医疗正文正确要求咨询医生，投资明确不能保证获利，危机正文优先现实求助。但投资摘要先要求补充“哪一卦、哪一爻”，与本轮风险支持目的冲突；三个场景仍出现“缺少原文所以无法解读”的多余限制说明。危机场景在未确认所在地时列举 120，未完全遵守当前提示词的地区约束。
- **出处可查，但工具成本增加。** 指定爻与朱熹注解命中正确材料。全库出处先未调用工具，经现有缺口反馈后搜索命中，又精确读取同一爻，模型请求由 3 次变为 5 次；不是完全重复参数的调用，但此次额外取证未增加新证据。两轮都未明确说明检出的坤卦不是本次乾卦，不能标成完整语义通过。

## 结论与任务状态
