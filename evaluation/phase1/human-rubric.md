# 第一阶段人工试评说明

本材料是固定开发输入的匿名输出试评，不是留出评测或已经完成的人工评分。
先读 materials.json，再在 scores.csv 填写。评分前不要打开上一级的 review-key 文件、comparison.csv、traces 或分析报告。
每份材料含同样需要的题目、核心问题、固定历史、程序卦象、回答和可查原文；策略和工具轨迹不在材料中。回答风格和所引材料仍可能暴露策略线索，不能宣称严格双盲。

逐份检查 summary、interpretation、reflection 全文，不只看带引用的段落：

- meaningSupport：填写 支持 / 部分支持 / 不支持 / 无法判断；解释的传统含义需能由提供证据支持。无法判断时如实标注，不凭引文存在给“支持”。在 notes 写出关键句、证据 ID 和原因。该标签针对整份输出，不是逐断言支持率。
- castConnection0to2：0=脱离卦象/串卦，1=有关联但生硬或失去关键意味，2=准确选取卦意并自然联系问题。日常追问可承接前义，不要求重复引用；资料缺失或风险支持题不强求解卦，可填 N/A。
- situationResponse0to2：0=没回答/编造关键条件，1=部分回应或泛泛建议，2=利用当前已知条件回答真正问题，不把旧助手意见当用户事实。
- proportion0to2：0=明显冗长、凶辞吓人或命令，1=基本合适但有多余内容，2=小事轻解、大事说清取舍，给有分寸的具体帮助。
- overRefusal、inventedFacts：填写 是 / 否 / 无法判断；answered 也可能回避问题，缺某作者资料的真实 insufficient 不是过度拒答。
- notes：写可核对的句子和依据；同时记不当确定性预测、对风险处理的问题。两个卦可以建议同一个行动，检查解释和分寸是否恰当，不要求相反答案。

每行填写真实 reviewer 身份。AI 辅助分析另存并标明，不得填成真人或专家评分。
14 份材料覆盖 7 个输入的两种输出；先逐份打分，再揭示配对关系讨论分歧。这里只有一位评审也可以开始，但不能称双人审查。没有评分时语义成功率保持 unknown。
