# 正式评测预注册 · 2026-10-10

目的：测量当前生产系统，不根据本轮输出调整模型、Prompt、检索、权限或校验器。基线 Git `4ae701bff993339dd7ab2c50c064d927ff17eae9`，graph v16 / prompt v16 / knowledge-v3-20260926-r1。主模型 Flash enabled/low/8192，单次 repair Flash disabled/8192。生产源码与数据、Rubric 的哈希在真实冒烟后、正式调用前冻结。评测脚本可修正，但不得篡改原请求或把评测工具修复冒充系统改善。

## 样本与划分

沿用计划中的40开发+40独立测试固定输入轮次；每split包含20生活、16知识和4风险/换题边界。与旧建议比例有调整：知识题独立统计，不能挤进核心自然交流平均分；边界验证与普通生活分开。按整个会话/衍生组划分；同问不同卦、同卦不同现实约束成对保留。独立组数由data.json计算，80轮次不是80独立用户。测试题不复用已见题干或其派生组；语料本身是共享发布集，不称知识文本留出。

开发与测试在本轮都不用于生产调优。标签由独立AI核对原典/注解，附真实ID、全文和出处，非专家Gold。输入与标签分文件；fixture只传问题、确定性卦象、用户/助手角色历史。生成器和策略不得读Gold。未知出处等自然说法不为规避现有parser缺陷改写。

## 实验矩阵与控制变量

- 固定输入：80×4=320单元。B仅初始证据；C为未修改的rules-c-v1；D为当前图关闭exact_target_request快捷取证；H为未修改的生产混合图。D仍保留首次直接生成、风险/已知缺失等确定性分支，不宣称是无限自主Agent。D/H只相差该快捷策略；B/C均使用既有route_policy注入，不复制生产服务。
- 知识输入：预先指定每split6题，共12×3=36单元。full使用C规则准备的当前原典+注解；classic过滤为原典；memory无文献且明确允许自身知识、引用为空。相同问题/卦象/历史/模型；每单元一次生成、不修复。memory的引文准确率和输入证据faithfulness为N/A，知识事实仍可对照评分参考。full不是人工Oracle，可能仍缺资料。
- 连续对话：4个会话×3轮=12轮，仅H；2开发/2测试，实际上轮完成回答进入下轮。已共享固定题组时明示，不能增加独立样本数。失败回合不当作已确认历史事实。
- 检索：离线R1双字组重合、R2 BM25、R3 BM25+用户声明的业务过滤，统一文本归一、短语加分和排序；服务端硬授权均保留。精确get_passages另表。K=1/3/5，不把检索命中当解释正确。
- 冒烟：3个已见graph输入+1个隔离FastAPI真实HTTP输入；验证v16、新建起卦、真实模型调用、持久化、重复请求不再调用及未授权读取拒绝。冒烟与正式数据分开。

每个固定输入四组同模型、初始证据、工具权限、校验与修复机制；四组并发，启动顺序按题轮换，最多4个在途单元。连续会话按时间顺序串行。索引提前加载，端到端时间不包含队列等待；供应商缓存与并发负载如实记录，因此不是单线程性能或线上SLA测量。每单元一次运行，不择优重跑；没有指定seed或temperature，不承诺字节级确定输出。

累计上限800次模型请求、5,000,000 reported或保守预留tokens，包含冒烟和失败；每个图单元最多8请求/100,000tokens，同时保留生产3次工具尝试、一次修复。BudgetedChat在await前同步预留，覆盖并发在途和repair。费用按真实usage和带日期价格快照估算，非账单。无usage保留unknown，无法计价不填0。预算停止、超时、未执行均留在预先建立的rows中。

## 预先约定的统计口径

- **机械完成**：图完成且最终校验无错；不足回答也可机械完成，不能称已完成知识任务。未执行/预算停止另列但保留计划分母。
- **任务完成**：AI或人工按问题要求判断，且实际有交付；与机械结果交叉形成端到端语义完成。被拒候选仅诊断，不替用户看到的失败提示计成功。人类尚未评分时记pending。
- **Schema**：首次与最后候选分别检查，说明计数分母；没有模型请求的确定性操作提示不算模型Schema样本。length空正文属于真实无效输出，不能因解析失败从分母消失。
- **引文**：ID/真实原文匹配、唯一原文恢复与错误归属分开。对应传统断言的支持程度由评审判断，不用机械匹配替代。
- **Repair**：触发单元数/有主生成单元数；修复后机械完成数/实际修复单元数。重复阶段诊断不作为独立请求成功率。
- **工具**：请求、预算尝试、执行ok、空结果、参数/权限拒绝分开。空结果不自动视为无效；是否必要与是否有效取决于初始证据、标签/人工判断。程序拒绝越权不计为泄露。
- **检索**：完整相关性集合才给严格Recall/Precision；部分AI正例只给已标注组覆盖、Hit及未知相关性边界。不把未标注命中自动当不相关；缺失题不进入非空Gold的召回分母。组内证据可替代，组间必须覆盖。
- **体验**：五维0–2及逐条原因，见rubric；生活、知识、边界各自报告。传统原义与现实类比分开，字数/段数不作为得分。Faithfulness检查citation claim并补出明显未引传统断言，说明覆盖不等于穷尽所有含义。
- **成本/延迟**：输入、输出、返回的reasoning细项、未知用量、缓存命中；P50/P95及原始分布，组别均值和失败开销。价格估算包含推理在completion内的费用，不重复收费。
- **不确定性**：成功率分子/分母及Wilson95%描述区间；成对差按groupId进行2000次bootstrap、seed1729。相关衍生题不当独立人群，小样本P95及AI主观分数不外推线上群体。

## 评阅与交付

Rubric在正式输出前固定。匿名材料隐藏模型/策略/Trace及既有评分，保留问题、必要历史、程序卦象、可用原文、完整正文与引用。人类评分CSV所有分数留空。AI评分标明身份；抽取预先确定子集由第二位独立AI复评，保留两份分数与分歧，不强行改成一致。其他项目记录为未双评，不冒称专家共识。

预定双评子集：测试集按caseId稳定排序的前4个生活case，四组共16份（以数据分类life为准）；可因数据字段命名映射而调整选择表达式，不按答案好坏选。知识消融和连续对话单独评阅；已见历史结果只作版本化参照，不混入本轮成功率。

最终报告同时交付所有原始结果、匿名人工包、统计脚本、可重算表、典型成功/失败、面试及简历可用表述。生产质量是否达标由用户阅读决定。完成数据分析后停止，不实施任何由本轮结果驱动的生产修正。
