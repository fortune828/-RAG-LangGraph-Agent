# 正式匿名对话评测协议 v1.0

准备日期：2026-10-10。状态：待主评测流程宣布冻结。此协议由 AI 制定并用于独立 AI 非专家评阅，不是人工评分、专家 Gold 或校勘定本。机器可读定义及评分记录 schema 见 rubric.json。

## 冻结与隔离

主流程宣布冻结后，不得按正式答案或组别结果修改五维、锚点、N/A、任务成功、文献核对或覆盖口径。仅可记录不改语义的错字/格式修正；实质变更须另建版本、另立评测，保留旧标准与原记录。准备本协议不代表已开始查看正式输出。

拟采用 4 个匿名条件，每条件 40 条 development、40 条 test，共 320 个回答单元；这是计划计数，不是已完成样本数。条件映射由运行方掌握，评阅员不接触策略名称或优劣预期。

只读匿名问题、必要卦象、该轮之前的真实历史、回答实际获得的证据、明确授权的参考材料与交付状态。不得读生产源码、提示词/策略、解盲键、stage rows、组别结论；独立提交前不得看另一评阅员分数。不得调用被测 API、重生成或操作 Git。后续才揭示的事实不倒扣前轮；其他样本拥有的文献不反算为本答当时已获得。领域、训诂或版本确实不明时记 unknown。

## 五维 0–2

0 为明确失败，1 为混合或明显不足，2 为在可核对范围内充分做到。N/A/无法判断以 null 表示，必须另写原因，不是 0。每维至少一句具体理由，有文本时附原句或准确短摘及位置；没有文本直接写明。

| 维度 | 2 | 1 | 0 |
|---|---|---|---|
| understanding：事实与更正 | 目标、条件、历史及最新纠正准确，保留未知 | 大体理解但遗漏重要条件、局部补事实或更正不充分 | 核心目标/角色/责任错置，继续依赖被纠正前提 |
| knowledge：经典解释 | 文义、作者、对象、范围与条件准确 | 有正确内容，也有局部误释、归属含混或条件遗漏 | 核心传统解释、所问对象或作者错误 |
| integration：现代联系 | 结构相关，现实判断有事实依据，边界清楚 | 有用联系与牵强对应、局部越界并存 | 核心依赖卦象确认事实/心理、保证结果或严重强套 |
| conversation：自然分寸 | 连贯、尊重、展开适度，能推进或收尾 | 跳接、过度纠正、机械展开或无益重开话题 | 严重失去连贯、忽略当前方向或妨碍交流 |
| helpfulness：实际帮助 | 核心查证/判断/下一步充分完成，有依据和取舍 | 部分有用但仍缺关键依据、条件、步骤或收尾 | 无实质帮助、方向错误或只有通用失败提示 |

五维分别判断，不按错误条数机械扣分，不默认求和排名。同一句可拆成传统解释、现代应用和用户事实：准确引文不使整段推论正确，牵强类比也不自动等于传统词义错误。清楚的文化比喻无需古文逐字谈现代生活；对应牵强本身可影响 integration，冒称原义、确认事实或预测则分别核对相应断言。条件方案不是用户已作出的决定，明确的假设也不是既定心理。

不用字数、段落数、引文数量、固定转折、追问数量衡量质量。复杂问题需要的深度是关键取舍和解释，不是篇幅；简单问题的问题是展开是否有用，而不是超过某个长度。

## N/A、候选与可见失败

- **完全没有可见回答的技术失败**：五维 null，原因 technical_no_answer；另列技术失败，taskSuccess=false。
- **完整候选未交付**：照常评分，target=candidate；候选能否完成需求另记 candidateTaskSuccess。不得将候选内容记成用户已得到的帮助；实际未交付则 taskSuccess=false。
- **仅通用核验失败提示**：understanding、knowledge、integration、conversation 为 null/no_substantive_content；helpfulness=0，taskSuccess=false。若另有候选，两个对象分别记录。
- **可读 insufficient/拒答**：不是空答案，按其理解、缺失说明与实际线索评分。未完成所需出处、原文或判断仍为 taskSuccess=false；诚实不等于高帮助。若相关证据本就未提供，不把缺失说明判作谎报；若已有足够材料，不能以 insufficient 冒充成功。
- **纯查证无现代应用**：integration=null/not_applicable。回答主动应用仍评应用；用户明确要求现实启发而未回应，不能用此条隐藏遗漏。
- **知识无法判断**：主要知识问题缺少可核定依据时 knowledge=null/insufficient_basis；局部未知与已核定部分分别说明，不把未知计为支持。没有传统断言可评时可 N/A，但核心任务遗漏须在理解、帮助和任务成功中体现。
- **未收集人工评分**：保持空白，不算 0，也不算某位真人作出了 N/A 判断。

## taskSuccess 独立记录

取 true、false、unknown，只针对用户实际看到的结果，不等于机械 completed，也不以五维总分阈值决定。

true：本轮核心要求已实质完成、必要事实和对象正确、没有改变结论的关键缺口。提供沟通建议不要求用户已执行，更不能保证对方反应。

false：未交付、仅失败提示、核心所问未答、决定性解释错误或关键更正被忽略。查出处并要原文时，只指出一个待查线索不算完成。诚实缺失说明可有部分帮助，仍不是查证成功。

unknown：关键文献或交付信息不足，无法负责判定；必须写清缺口。不能因没有专家 Gold 就把所有成功判断都记 unknown。

候选另设 candidateTaskSuccess，不进入已交付成功率。次要无关错误不一定否定已完成的核心任务，但必须留下维度分与错误；关键误释、错作者或错误对象不能被“有一段原文”掩盖。

## 错误记录

每条必须有原句、位置、理由、所对照事实/来源、影响维度、严重度（minor/material/critical）和确定度（confirmed/suspected/unknown）。没有实际问题就留空，不为填表寻找错误。名称描述输出，不推断模型故意欺骗。

| 类型 | 含义 |
|---|---|
| fabricated_fact | 未提供的时点、次数、角色、安排或承诺被说成事实 |
| unsupported_psychology | 无依据断言用户或他人动机、情绪、性格 |
| missed_correction / history_contradiction | 未采用最新纠正，或与既有历史事实冲突 |
| wrong_attribution | 作者、书名、卦爻或观点归属错误 |
| wrong_classical_meaning | 文义、占义或注家条件误释 |
| scope_overgeneralization | 特定爻、作者或条件被推广成全卦/普遍规律 |
| citation_mismatch | 引文改义、错对象或不能支持所称传统观点 |
| strained_analogy | 对应缺少相关结构，或启发被强行等同 |
| unsupported_prediction | 无依据的现实因果、未来、关系结果或保证 |
| unsupported_requirement | 添加无根据的硬步骤、次数规则、另起卦要求 |
| unhelpful_expansion | 扩展制造顾虑、重开已解决问题，未增加所需帮助 |
| task_not_answered | 未完成所需对象、解释、原文或判断 |
| misleading_missingness | 实际已有相关材料却声称没有 |

疑义明确记录，unknown 不作为已证实错误自动给 0。一个句子含多个断言可分别标记；不得把一项错误不加理由地重复惩罚所有维度。

## Faithfulness 独立核对

固定口径：**逐个审阅所有 citation claim，并补出明显未引用的传统断言**。这包括词义、作者观点、爻名、范围、历史解释条件和占法要求；不是只测引文子串匹配。

1. 先区分引文、传统解释、作者归属、现代类比、现实事实与预测。混合句拆成能判断的命题，保留原句和位置。
2. 每个 citation claim occurrence 都登记审阅；重复引用保留位置。同一传统命题可去重，不能用重复引文增加质量权重。
3. 补出明显未引证传统断言。未引用不自动判错；缺 source 的样本不能被简单算作引用率 0。
4. 只用本答实际证据及明确授权参考，记录来源边界。某段句子匹配，不代表省略条件、词义解释或全段断言都获支持。
5. 逐字匹配另记 quotationMatch：exact、normalized、partial、mismatch、not_applicable、unknown。标点、空格、繁简等不改义规范化可以接受；不能把规范化当成允许改义。
6. 独立标支持关系：supported、partial、unsupported、unknown。现代比喻若只是明示启发，不进入传统命题支持分母，标签 null 并说明排除原因；不能因古文不谈现代场景就计为不支持。冒称原义的现代句需拆出传统断言；借经文证明现实结果则在 integration 与错误表中记录。

| 标签 | 标准 |
|---|---|
| supported | 证据支持该断言的对象、内容、条件和范围 |
| partial | 有支持部分，也有条件省略、扩大或不充分部分；逐项说明 |
| unsupported | 可核对证据不支持、范围不符或直接矛盾；矛盾另标 contradiction=true |
| unknown | 缺相关原文、版本/归属/训诂无法核定；不是自动判假 |

覆盖字段必须保留：引用 claim 出现总数/已审数；识别出的传统断言总数/已审数；明显未引传统断言数/已审数；uncitedDiscoveryExhaustive=false；遗漏或限制说明。识别到的断言覆盖不等于已经穷尽所有隐含断言。

统计四类数量及分母，不任意把 partial 折成 0.5。若算已知支持率，分母为 supported+partial+unsupported，必须同时报 unknown 数量及其占全部传统命题的比例；无适用命题报告 N/A，不伪报 0% 或 100%。Faithfulness 不能代替 knowledge，更不能代替整体语义：全部引文字面正确仍可能伴随错误解释、心理归因或现实预测。

## 独立复评、人工字段与汇总

初评与复评使用同一冻结版本，先独立提交再对照，保留原始记录。分歧以具体原句、事实和证据核对，无法解决则保留分歧或 unknown，不参照匿名组身份。若另设裁决，记录其 AI/人工身份及修改理由，不覆盖原分数；AI 裁决不叫人工 Gold。

人类 CSV 默认只有表头、没有数据行。全部人工评分、理由、身份与结论默认空白；如生成样本占位行，也不得复制 AI 分数或虚构真人。只有实际真人提交后才写值；真实 N/A 要有原因，真实 0 写 0，未收集继续空白。字段定义见 rubric.json 的 humanCsv，不在本准备步骤伪造人工 CSV 内容。

分别报告五维分布、均值和有效 n，另列 N/A、unknown、技术失败、候选与可见失败提示。任务成功和交付独立报告；同题多条件、连续轮次有相关性，不把每条当独立随机样本。若需总分权重或排名规则，须在看正式输出前另行冻结，不能根据结果挑权重、删样本或改支持覆盖口径。
