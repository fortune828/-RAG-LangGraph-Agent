# 独立代码复核与保守修复 · 2026-10-10

本报告来自独立子 agent 的源码与离线测试复核，属于 AI 工程审查，不是人工体验评分或专家文献校勘。复核未读取冻结留出输入、输出，未调用真实模型 API。v14 冻结实验保持原样；本次保守修复由主 agent 单独标为 graph v15，不能把 v14 的真实结果重新标成 v15。

## 1. 已证实的问题及本次处理

### 精确检索捷径会绕过隐含换题判定

`backend/graph.py:293` 的生产路由先调用 `exact_target_request`；只有返回 `None` 才请求模型 Router。Router 同时承担追问是否变成新核心问题的判断，`backend/graph.py:310` 接受其 `newTopic=true` 后结束本轮，工具尚未执行。

原精确捷径只检查目标是否明确、材料是否可得，没有检查整个提问是否仅为文献请求。离线复现：会话核心是午饭，追问变成“我和对象分手了，本卦第二爻对复合这件事有什么启发？”。目标解析仍能得到第二爻；捷径取得原文后直接生成，Router 没有机会判定换题。这是可观察的流程回归，不是模型回答质量的推测。

本次在 `backend/retrieval.py:9` 定义一个小的正向请求语法，`backend/retrieval.py:34` 用完整匹配决定是否采用捷径。范围限定为“本卦/当前卦 + 明确爻位或章节 + 文献请求”，可附固定的文义问法。例如：

- 请给出本卦第二爻原文。
- 请查本卦九二爻辞和小象。
- 本卦第三爻和第四爻原文是什么？
- 请给出本卦第二爻原文，并解释其含义。

未识别的剩余文字、生活处境、指定作者或书名，以及任意引文均保留模型路由。这不是完整的意图识别器，也不尝试用领域关键词黑名单猜测换题。保守回退会减少可节省的模型请求，但不会撤销原 Router 的理解机会。

回归证据：`tests_python/test_router_efficiency.py:99` 验证同题生活与原文混合请求仍先路由；`:113` 验证隐含新题的 Router 即使同时提出工具调用，`newTopic=true` 仍优先结束，实际工具尝试为 0、会话卦象保持不变。这里使用模拟 Router，证明控制流正确，不证明真实模型一定识别所有换题。

### 多卦、多爻的对应关系已经在旧解析器中丢失

`backend/validation.py:30` 分别收集卦号、爻号，`:53` 将它们做交叉组合。“乾卦九二和坤卦六三”因此变成乾二、乾三、坤二、坤三四个目标。精确 helper 的合并没有新增超出这些解析目标的对象，但解析目标本身已多于用户所问。

本次在 `backend/retrieval.py:36` 增加独立 guard：同时出现多个卦号、多个爻号时，不自动规划，交还 Router。正向语法目前也不接受任意命名卦组合。两道限制仅阻止确定性捷径放大歧义，不声称修好了关系解析。

**仍未解决：**Router 接收到的 `required_targets` 仍可能是错误交叉组合，`backend/validation.py:131` 的最终校验也仍要求这些目标全部被引用。模型即使正确理解原话，仍可能被旧目标约束要求多取材料或进入修复。因此该类多对象配对问题只能列为局限，不能纳入“已正确支持”能力声明。以后如实际需求值得投入，应修复目标关系解析及对应校验，而不是扩大这次捷径的语法。

`tests_python/test_router_efficiency.py:132` 同时记录“回到 Router”和“四个交叉目标仍存在”，避免把保守回退误报成原问题已解决。

## 2. 其他已检查的边界

| 边界 | 复核结果与范围 |
|---|---|
| 工具权限与预算 | helper 只构造消息，不执行工具；授权范围、规范参数、重复请求、剩余三次尝试仍由 helper 和图工具节点各自检查。全库未知出处、宽泛作者目标、未识别书名、发布集缺失目标不会由捷径猜测完成。 |
| 请求合并 | 同卦、层、作者、作品分组；只有 section 集合完全相同的 line 才组成矩形批次，避免 `sections × lineIndices` 引入额外对象。此保证仅针对已经解析的目标，不修复上游关联丢失。 |
| 静卦注解 | `backend/knowledge.py:144` 的候选注解限制为实际动爻与显式指定爻位，并限定本卦；静卦无明确爻位不再因现代提问中“不能”等共享词而预灌任意爻注。原典、工具能力、每轮注家上限和语料正文/发布版本保持。相关性约束本身不证明解释语义改善。 |
| 引文回填 | `backend/citations.py:22` 仅在同一证据中定位唯一的简繁、标点/空白归一对应片段并恢复来源原文；不改 claim 或正文。虚构词句、歧义匹配、未知证据 ID、归属错误和 Schema 超长仍被拒绝。原有直接匹配路径保持；通过校验不代表解释正确。 |
| 生成截断 | 被供应商标为 length 的响应即使局部可解析也不能当成功答案；只进入已有的一次修复，修复再截断即失败。保留原响应已报告 usage，缺失用量为未知；不将内部推理文本交给修复或记录为用户答案。路由截断仍传播错误，不冒充正文修复。 |
| 爻名 | 程序生成实际阴阳对应的爻名，相关枚举测试覆盖各卦；不由模型重新计算。 |

静卦关键词漂移已有离线复现：将责任更正提问改写成含“不能”的自然句时，原候选排序会选入恒卦不同爻的注解，仅共享该词即可命中。这说明存在材料相关性缺口。它不证明某条历史回答必然由这些初始材料造成；部分原始问题初始没有这些注解，后续工具也可能取得材料，归因应依照逐次运行记录。
